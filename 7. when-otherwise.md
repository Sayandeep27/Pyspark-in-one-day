# PySpark `when()` and `otherwise()` — Complete Guide

---

## 📌 Overview

In **PySpark**, `when()` and `otherwise()` are used to implement **conditional logic** (similar to `IF-ELSE` in SQL or Python).

They are part of:

```python
from pyspark.sql.functions import when
```

---

## 🧠 Concept Mapping

| PySpark     | SQL       | Python |
| ----------- | --------- | ------ |
| when()      | CASE WHEN | if     |
| otherwise() | ELSE      | else   |

---

## ⚙️ Syntax

```python
from pyspark.sql.functions import when, col

# Basic syntax

df.withColumn(
    "new_column",
    when(condition, value_if_true).otherwise(value_if_false)
)
```

---

## 📊 Example 1: Basic IF-ELSE

### Input Data

| id | marks |
| -- | ----- |
| 1  | 85    |
| 2  | 40    |
| 3  | 60    |

### Code

```python
df = df.withColumn(
    "result",
    when(col("marks") >= 50, "Pass").otherwise("Fail")
)
```

### Output

| id | marks | result |
| -- | ----- | ------ |
| 1  | 85    | Pass   |
| 2  | 40    | Fail   |
| 3  | 60    | Pass   |

---

## ⚠️ Without `otherwise()`

```python
df = df.withColumn(
    "result",
    when(col("marks") >= 50, "Pass")
)
```

### Output

| id | marks | result |
| -- | ----- | ------ |
| 1  | 85    | Pass   |
| 2  | 40    | NULL   |
| 3  | 60    | Pass   |

🔴 **Important:** If `otherwise()` is not used, unmatched rows return `NULL`.

---

## 🔁 Example 2: Multiple Conditions (Chaining)

```python
df = df.withColumn(
    "grade",
    when(col("marks") >= 80, "A")
    .when(col("marks") >= 50, "B")
    .otherwise("Fail")
)
```

### Output

| id | marks | grade |
| -- | ----- | ----- |
| 1  | 85    | A     |
| 2  | 40    | Fail  |
| 3  | 60    | B     |

---

## 🧩 Example 3: Multiple Conditions with Different Columns

### Input Data

| id | age | salary |
| -- | --- | ------ |
| 1  | 25  | 30000  |
| 2  | 40  | 80000  |
| 3  | 30  | 50000  |

### Code

```python
df = df.withColumn(
    "category",
    when((col("age") < 30) & (col("salary") < 40000), "Junior")
    .when((col("age") >= 30) & (col("salary") >= 50000), "Senior")
    .otherwise("Mid")
)
```

---

## 🧮 Example 4: Using with `select()`

```python
df.select(
    "id",
    when(col("marks") >= 50, "Pass").otherwise("Fail").alias("result")
)
```

---

## 🔄 Example 5: Nested Conditions

```python
df = df.withColumn(
    "grade",
    when(col("marks") >= 80, "A")
    .otherwise(
        when(col("marks") >= 50, "B").otherwise("Fail")
    )
)
```

---

## 🧹 Example 6: Data Cleaning (Handling NULL)

```python
df = df.withColumn(
    "cleaned_marks",
    when(col("marks").isNull(), 0).otherwise(col("marks"))
)
```

---

## 🚀 Example 7: Creating Flags

```python
df = df.withColumn(
    "is_high_value",
    when(col("salary") > 70000, 1).otherwise(0)
)
```

---

## 🔗 Example 8: Using with `filter()`

```python
df.filter(
    when(col("marks") > 50, True).otherwise(False)
)
```

---

## 🧾 SQL Equivalent

```sql
SELECT *,
       CASE
           WHEN marks >= 50 THEN 'Pass'
           ELSE 'Fail'
       END AS result
FROM table_name;
```

---

## ⚡ Key Points (Must Remember)

* `otherwise()` is **optional but highly recommended**
* Without `otherwise()` → result is **NULL** for unmatched rows
* Can chain multiple `when()` conditions
* Works inside `withColumn()` and `select()`
* Supports complex logical conditions using `&`, `|`, `~`

---

## ⚠️ Common Mistakes

| Mistake                              | Explanation                        |               |
| ------------------------------------ | ---------------------------------- | ------------- |
| Missing `otherwise()`                | Leads to NULL values               |               |
| Using Python `and/or` instead of `&/ | `                                  | Causes errors |
| Not using `col()`                    | Column reference fails             |               |
| Incorrect chaining                   | `.when()` must be chained properly |               |

## 🧪 Advanced Example (End-to-End)

### Input Data

| id | age | salary | marks |
| -- | --- | ------ | ----- |
| 1  | 25  | 30000  | 85    |
| 2  | 40  | 80000  | 40    |
| 3  | 30  | 50000  | 60    |

### Code

```python
from pyspark.sql.functions import when, col

# Add multiple derived columns

df = df \
.withColumn(
    "result",
    when(col("marks") >= 50, "Pass").otherwise("Fail")
) \
.withColumn(
    "grade",
    when(col("marks") >= 80, "A")
    .when(col("marks") >= 50, "B")
    .otherwise("Fail")
) \
.withColumn(
    "category",
    when(col("salary") > 70000, "High")
    .when(col("salary") >= 40000, "Medium")
    .otherwise("Low")
)
```
