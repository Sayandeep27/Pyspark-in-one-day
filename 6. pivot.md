# 🚀 PySpark Pivot – Complete Guide

---

## 1️⃣ Introduction

Pivot operation in **PySpark** is used for **data reshaping**. It helps transform row-level data into columnar format, making it easier for reporting and analysis.

---

## 2️⃣ What is Pivot?

Pivot converts **unique values from a column into multiple columns** and applies aggregation.

### 🔹 Simple Definition

> Pivot = Convert rows into columns + aggregate values

---

## 3️⃣ Syntax

```python
# Basic Syntax

df.groupBy("group_column") \
  .pivot("pivot_column") \
  .agg(aggregation_function)
```

---

## 4️⃣ Step-by-Step Example

### 🔹 Input Data

| Name | Subject | Marks |
| ---- | ------- | ----- |
| A    | Math    | 90    |
| A    | Eng     | 80    |
| B    | Math    | 70    |
| B    | Eng     | 60    |

---

### 🔹 Code

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import sum

spark = SparkSession.builder.appName("PivotExample").getOrCreate()

# Sample Data
data = [
    ("A", "Math", 90),
    ("A", "Eng", 80),
    ("B", "Math", 70),
    ("B", "Eng", 60)
]

columns = ["Name", "Subject", "Marks"]

df = spark.createDataFrame(data, columns)

# Pivot Operation
pivot_df = df.groupBy("Name") \
             .pivot("Subject") \
             .sum("Marks")

pivot_df.show()
```

---

### 🔹 Output

| Name | Eng | Math |
| ---- | --- | ---- |
| A    | 80  | 90   |
| B    | 60  | 70   |

---

## 5️⃣ How Pivot Works Internally

| Step | Operation   | Explanation                         |
| ---- | ----------- | ----------------------------------- |
| 1    | groupBy     | Groups data based on key column     |
| 2    | pivot       | Converts unique values into columns |
| 3    | aggregation | Applies function like sum/avg       |

---

## 6️⃣ Multiple Aggregations

```python
from pyspark.sql.functions import sum, avg

multi_agg_df = df.groupBy("Name") \
    .pivot("Subject") \
    .agg(
        sum("Marks").alias("Total"),
        avg("Marks").alias("Average")
    )

multi_agg_df.show()
```

---

## 7️⃣ Pivot with Specific Values (Optimization)

```python
optimized_df = df.groupBy("Name") \
    .pivot("Subject", ["Math", "Eng"]) \
    .sum("Marks")
```

### ✅ Why use this?

* Avoids scanning all distinct values
* Improves performance
* Reduces shuffle overhead

## 8️⃣ Real-Life Example (Sales Data)

### 🔹 Input Data

| Region | Product | Sales |
| ------ | ------- | ----- |
| East   | A       | 100   |
| East   | B       | 200   |
| West   | A       | 150   |
| West   | B       | 250   |

---

### 🔹 Code

```python
sales_data = [
    ("East", "A", 100),
    ("East", "B", 200),
    ("West", "A", 150),
    ("West", "B", 250)
]

columns = ["Region", "Product", "Sales"]

df = spark.createDataFrame(sales_data, columns)

result = df.groupBy("Region") \
    .pivot("Product") \
    .sum("Sales")

result.show()
```

---

### 🔹 Output

| Region | A   | B   |
| ------ | --- | --- |
| East   | 100 | 200 |
| West   | 150 | 250 |

---

## 9️⃣ Performance Considerations ⚠️

* Pivot triggers **shuffle operation**
* Can be expensive on large datasets

### ✅ Best Practices

* Filter data before pivot
* Use **explicit pivot values**
* Avoid high cardinality columns
* Cache intermediate results if reused

---

## 🔟 Unpivot (Reverse of Pivot)

PySpark does not provide direct unpivot, but we can use:

### 🔹 Using stack()

```python
from pyspark.sql.functions import expr

unpivot_df = pivot_df.select(
    "Name",
    expr("stack(2, 'Math', Math, 'Eng', Eng) as (Subject, Marks)")
)

unpivot_df.show()
```

## 1️⃣1️⃣ Interview Questions

### ❓ Q1: Why is pivot expensive?

Because it causes **data shuffle across partitions**.

---

### ❓ Q2: How to optimize pivot?

* Provide pivot values explicitly
* Reduce dataset size before pivot

---

### ❓ Q3: Difference between groupBy and pivot?

| Feature  | groupBy         | pivot              |
| -------- | --------------- | ------------------ |
| Output   | Aggregated rows | Aggregated columns |
| Use Case | Summarization   | Data reshaping     |
