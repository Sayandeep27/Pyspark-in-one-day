# PySpark: split(), Indexing, and explode() — Complete Guide

---

## 📌 Overview

This document provides a **complete, interview-ready explanation** of the following PySpark functions:

* `split()` → Convert string to array
* **Indexing** → Access elements from array
* `explode()` → Flatten array into multiple rows

These functions are heavily used in:

* ETL pipelines
* Data cleaning
* Log processing
* NLP preprocessing

---

## 📊 Sample Input Data

We start with a simple dataset:

| id | name  | skills             |
| -- | ----- | ------------------ |
| 1  | John  | Python,SQL,Tableau |
| 2  | Alice | Java,Scala         |
| 3  | Bob   | Python             |

---

## 🔹 1. split() Function

### ✅ Purpose

Convert a **string column into an array column**.

### 🧠 Syntax

```python
split(column, delimiter)
```

### 💻 Code Example

```python
from pyspark.sql.functions import split

df_split = df.withColumn("skills_array", split(df["skills"], ","))
```

### 📤 Output

| id | name  | skills             | skills_array           |
| -- | ----- | ------------------ | ---------------------- |
| 1  | John  | Python,SQL,Tableau | [Python, SQL, Tableau] |
| 2  | Alice | Java,Scala         | [Java, Scala]          |
| 3  | Bob   | Python             | [Python]               |

### 🔍 Explanation

* Splits string using delimiter `,`
* Output is an **array (list-like structure)**

---

## 🔹 2. Indexing in PySpark Arrays

### ✅ Purpose

Access a **specific element from an array column**

### 🧠 Key Point

* PySpark uses **0-based indexing**

### 💻 Code Example

```python
df_index = df_split.withColumn("first_skill", df_split["skills_array"][0])
```

### 📤 Output

| id | name  | skills_array           | first_skill |
| -- | ----- | ---------------------- | ----------- |
| 1  | John  | [Python, SQL, Tableau] | Python      |
| 2  | Alice | [Java, Scala]          | Java        |
| 3  | Bob   | [Python]               | Python      |

### 🔍 Explanation

* `[0]` → first element
* `[1]` → second element

---

## 🔹 3. explode() Function

### ✅ Purpose

Convert **array elements into multiple rows**

### 💻 Code Example

```python
from pyspark.sql.functions import explode

df_explode = df_split.withColumn("skill", explode(df_split["skills_array"]))
```

### 📤 Output

| id | name  | skill   |
| -- | ----- | ------- |
| 1  | John  | Python  |
| 1  | John  | SQL     |
| 1  | John  | Tableau |
| 2  | Alice | Java    |
| 2  | Alice | Scala   |
| 3  | Bob   | Python  |

### 🔍 Explanation

* One row becomes **multiple rows**
* Helps in **data normalization**

---

## 🔁 Full Transformation Flow

| Step      | Transformation        |
| --------- | --------------------- |
| split()   | String → Array        |
| indexing  | Array → Single value  |
| explode() | Array → Multiple rows |

---

## 🔗 Combined Example (Production Use Case)

### 💻 Code

```python
from pyspark.sql.functions import split, explode

df_final = df.withColumn("skills_array", split("skills", ",")) \
             .withColumn("skill", explode("skills_array"))
```

### 📤 Final Output

| id | name  | skill   |
| -- | ----- | ------- |
| 1  | John  | Python  |
| 1  | John  | SQL     |
| 1  | John  | Tableau |
| 2  | Alice | Java    |
| 2  | Alice | Scala   |
| 3  | Bob   | Python  |

## ⚡ Important Interview Points

* `split()` converts **string → array**
* Indexing extracts **specific value from array**
* `explode()` converts **array → rows**

  * Data engineering pipelines
