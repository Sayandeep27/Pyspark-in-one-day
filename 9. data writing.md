## 1️⃣ Introduction

**Data Writing in PySpark** refers to saving a DataFrame into storage systems such as:

* Files (CSV, JSON, Parquet, ORC, Avro)
* Databases (MySQL, PostgreSQL, etc.)
* Hive Tables
* Data Lakes (HDFS, S3, ADLS)

---

## 2️⃣ Why Data Writing is Important

| Reason      | Description                          |
| ----------- | ------------------------------------ |
| Persistence | Save processed data permanently      |
| Sharing     | Share results across systems         |
| Reusability | Use data for ML / BI / Analytics     |
| Performance | Store optimized formats like Parquet |

---

## 3️⃣ Basic Syntax

```python
df.write \
  .format("format_name") \
  .option("key", "value") \
  .mode("write_mode") \
  .save("path")
```

---

## 4️⃣ Write Modes

| Mode                  | Description                    |
| --------------------- | ------------------------------ |
| append                | Adds new data to existing data |
| overwrite             | Replaces existing data         |
| ignore                | Skips writing if data exists   |
| error / errorifexists | Throws error if data exists    |

### Example

```python
df.write.mode("overwrite").csv("/output/path")
```

## 5️⃣ Writing to Different Formats

### 📄 CSV

```python
df.write \
  .format("csv") \
  .option("header", True) \
  .mode("overwrite") \
  .save("/output/csv")
```

---

### 🧾 JSON

```python
df.write \
  .format("json") \
  .mode("overwrite") \
  .save("/output/json")
```

---

### ⚡ Parquet (Recommended)

```python
df.write \
  .format("parquet") \
  .mode("overwrite") \
  .save("/output/parquet")
```

✔ Columnar format
✔ Faster queries
✔ Compression support

---

### 🧊 ORC

```python
df.write \
  .format("orc") \
  .mode("overwrite") \
  .save("/output/orc")
```

---

### 🔥 Avro

```python
df.write \
  .format("avro") \
  .mode("overwrite") \
  .save("/output/avro")
```

---

## 6️⃣ Writing to Databases (JDBC)

```python
df.write \
  .format("jdbc") \
  .option("url", "jdbc:mysql://localhost:3306/db") \
  .option("dbtable", "table_name") \
  .option("user", "root") \
  .option("password", "password") \
  .mode("append") \
  .save()
```

---

## 7️⃣ Partitioning & Bucketing

### 🔹 Partitioning

```python
df.write \
  .partitionBy("column_name") \
  .mode("overwrite") \
  .parquet("/output/partitioned")
```

✔ Improves query performance
✔ Reduces scan size

---

### 🔹 Bucketing

```python
df.write \
  .bucketBy(4, "column_name") \
  .sortBy("column_name") \
  .saveAsTable("bucketed_table")
```

✔ Used in joins
✔ Works only with tables

---

## 8️⃣ Save vs SaveAsTable

| Method        | Description          |
| ------------- | -------------------- |
| save()        | Saves to file system |
| saveAsTable() | Saves as Hive table  |

### Example

```python
df.write.mode("overwrite").saveAsTable("sales_table")
```

---

## 9️⃣ Best Practices

* Prefer **Parquet** for performance
* Use **partitioning** for large datasets
* Avoid too many small files
* Use **overwrite cautiously**
* Optimize using **repartition() / coalesce()**

## 🔟 Complete Example

```python
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("WriteExample").getOrCreate()

# Sample Data
data = [(1, "A", 100), (2, "B", 200)]
columns = ["id", "category", "amount"]

df = spark.createDataFrame(data, columns)

# Writing Data

df.write \
  .format("parquet") \
  .partitionBy("category") \
  .mode("overwrite") \
  .save("/output/final")
```
