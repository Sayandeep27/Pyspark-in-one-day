# PySpark `collect_list()` – Complete Guide

---

## 📌 Overview

`collect_list()` is a **PySpark aggregation function** used to collect values from multiple rows into a **list (array)**.

It is commonly used with `groupBy()` to aggregate data into array format.

---

## ⚙️ Key Characteristics

| Feature         | Description                        |
| --------------- | ---------------------------------- |
| Type            | Aggregation Function               |
| Output          | Array (List)                       |
| Duplicates      | Allowed                            |
| Order Guarantee | ❌ Not guaranteed                   |
| Works With      | groupBy(), agg(), Window functions |

---

## 🧠 Syntax

```python
from pyspark.sql.functions import collect_list

# Basic Syntax
df.groupBy("column_name").agg(collect_list("target_column"))
```

---

## 📊 Example 1: Basic Usage

### 🔹 Input Data

| Dept | Employee |
| ---- | -------- |
| HR   | A        |
| HR   | B        |
| IT   | C        |
| IT   | D        |
| IT   | C        |

---

### 🔹 PySpark Code

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import collect_list

spark = SparkSession.builder.getOrCreate()

# Sample Data
data = [
    ("HR", "A"),
    ("HR", "B"),
    ("IT", "C"),
    ("IT", "D"),
    ("IT", "C")
]

# Create DataFrame
df = spark.createDataFrame(data, ["Dept", "Employee"])

# Apply collect_list
result_df = df.groupBy("Dept") \
    .agg(collect_list("Employee").alias("Employee_List"))

result_df.show(truncate=False)
```

---

### 🔹 Output

| Dept | Employee_List |
| ---- | ------------- |
| HR   | [A, B]        |
| IT   | [C, D, C]     |

---

## 🚨 Important Notes

### 1. Duplicates are Included

`collect_list()` keeps duplicate values:

```
IT → [C, D, C]
```

---

### 2. Order is NOT Guaranteed

Spark does **not guarantee order** of elements inside the list.

To enforce order, use:

```python
from pyspark.sql.functions import sort_array

result_df = df.groupBy("Dept") \
    .agg(sort_array(collect_list("Employee")).alias("Sorted_List"))
```

---

## 🔄 Example 2: Remove Duplicates using `collect_set()`

### 🔹 Code

```python
from pyspark.sql.functions import collect_set

result_df = df.groupBy("Dept") \
    .agg(collect_set("Employee").alias("Unique_Employees"))

result_df.show()
```

---

### 🔹 Output

| Dept | Unique_Employees |
| ---- | ---------------- |
| HR   | [A, B]           |
| IT   | [C, D]           |

---

## 🧩 Example 3: Collect Multiple Columns

### 🔹 Code

```python
from pyspark.sql.functions import struct

result_df = df.groupBy("Dept") \
    .agg(collect_list(struct("Employee")).alias("Employee_Details"))

result_df.show(truncate=False)
```

---

### 🔹 Output

| Dept | Employee_Details |
| ---- | ---------------- |
| HR   | [{A}, {B}]       |
| IT   | [{C}, {D}, {C}]  |

---

## 🪟 Example 4: Using `collect_list()` with Window Functions

### 🔹 Code

```python
from pyspark.sql.window import Window
from pyspark.sql.functions import collect_list

window_spec = Window.partitionBy("Dept")

result_df = df.withColumn(
    "Employee_List",
    collect_list("Employee").over(window_spec)
)

result_df.show()
```

---

### 🔹 Output

| Dept | Employee | Employee_List |
| ---- | -------- | ------------- |
| HR   | A        | [A, B]        |
| HR   | B        | [A, B]        |
| IT   | C        | [C, D, C]     |
| IT   | D        | [C, D, C]     |
| IT   | C        | [C, D, C]     |

## 🧪 Example 5: Real-World Use Case

### 🔹 Problem

Collect all products purchased by each customer.

### 🔹 Code

```python
data = [
    ("Cust1", "P1"),
    ("Cust1", "P2"),
    ("Cust2", "P3"),
    ("Cust2", "P4"),
    ("Cust2", "P3")
]

columns = ["Customer", "Product"]

df = spark.createDataFrame(data, columns)

result_df = df.groupBy("Customer") \
    .agg(collect_list("Product").alias("Products"))

result_df.show(truncate=False)
```

---

### 🔹 Output

| Customer | Products     |
| -------- | ------------ |
| Cust1    | [P1, P2]     |
| Cust2    | [P3, P4, P3] |

---

## ⚖️ `collect_list()` vs `collect_set()`

| Feature          | collect_list() | collect_set() |
| ---------------- | -------------- | ------------- |
| Duplicates       | ✅ Yes          | ❌ No          |
| Order Guaranteed | ❌ No           | ❌ No          |
| Output Type      | Array          | Array         |

---

## 🎯 When to Use `collect_list()`

* Grouping related values into arrays
* Creating sequence-based ML features
* Building nested JSON structures
* Aggregating logs/events per user

---

## 🚀 Best Practices

* Use `sort_array()` if order matters
* Use `collect_set()` if duplicates are not required
* Be cautious with large datasets (can increase memory usage)
