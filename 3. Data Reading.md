# 🚀 PySpark Data Reading Techniques (A → Z)

A complete, professional guide covering **all data reading techniques in PySpark** with examples, syntax, and outputs.

# 1️⃣ Basic Syntax

```python
df = spark.read.format("file_format") \
    .option("key", "value") \
    .load("path")
```

OR shortcut:

```python

df = spark.read.json("path")
```

---

# 2️⃣ Reading CSV Files

## Syntax

```python
df = spark.read.csv("path", header=True, inferSchema=True)
```

## Example

### Input (data.csv)

```
id,name,age
1,Alice,25
2,Bob,30
```

### Code

```python
df = spark.read.csv("data.csv", header=True, inferSchema=True)
df.show()
```

### Output

```
+---+-----+---+
|id |name |age|
+---+-----+---+
|1  |Alice|25 |
|2  |Bob  |30 |
+---+-----+---+
```

### Important Options

| Option           | Description               |
| ---------------- | ------------------------- |
| header=True      | First row as column names |
| inferSchema=True | Auto detect types         |
| sep=","          | Delimiter                 |
| nullValue="NA"   | Handle null values        |

# 9️⃣ Reading with Schema

## Define Schema

```python
from pyspark.sql.types import *

schema = StructType([
    StructField("id", IntegerType(), True),
    StructField("name", StringType(), True),
    StructField("age", IntegerType(), True)
])
```

## Read Data

```python
df = spark.read.csv("data.csv", schema=schema, header=True)
```

# 1️⃣1️⃣ Reading from Database (JDBC)

    .option("password", "password") \
    .load()

# 🎯 Interview Points

* Parquet is fastest and default format
* Schema inference is expensive
* Spark uses lazy evaluation
* Data is processed in partitions
* Wide transformations cause shuffle
